# Bloqueios de publicacao

## Bloqueadores

- CDC x CTN.
- Encoding visivel.
- Conteudo sem objetivo.
- Conteudo sem disciplina quando obrigatoria.
- Questoes sem resposta.
- Flashcards incompletos.
- Mapas sem unidade pedagogica.
- Leis sem versao.
- Provas sem identificacao minima.
- Duplicacao suspeita.

## Decisao CDC x CTN

Bloquear ambos os texto.txt suspeitos, permitir artigos.json apenas se validado contra fonte oficial, buscar fonte oficial, substituir depois e validar hashes. Nao corrigir agora.
